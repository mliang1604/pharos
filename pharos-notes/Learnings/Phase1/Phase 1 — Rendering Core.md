# **Milestone goal**
A reusable rendering API — meshes, materials, cameras, scene graph, basic lighting.

# Learning Notes

- [[Issue 11 - Mesh Class]] — vertex/index buffer abstraction: string-literal format unions with `Record` exhaustiveness, deriving layouts/offsets/counts instead of duplicating them, the grouped-optional index buffer, `readonly` immutability over getters/setters, encapsulating the draw, and the `ArrayBuffer` pinning gotcha revisited (pin the type, don't cast).
- [[Issue 12 - Material and Shader]] — the appearance half: WGSL extracted to a file via Vite `?raw`, a thin `Shader` (one module, two entry points), a `UniformBuffer` helper, and a Thin `Material` that owns pipeline + bind group through `layout: 'auto'` introspection. Through-line: lifetime ownership — only store what outlives the constructor (and keep what does). Scoped to group 0; the bind-group strategy is next.
- [[Issue 13 - Bind Group Strategy]] — defining a convention rather than building a thing: bind groups grouped by update frequency (per-frame / per-material / per-object) to minimize rebinds, encoded as an `as const` `BindGroup` constant (not a numeric enum). Through-line: establish the contract before you can consume it — the cube stays a single-group case (no fake-wiring), and the real three-way split is owned by the next issues (camera → group 0, `Node` → group 2). Plus a Windows case-insensitive-filename gotcha.
- [[Issue 14 - Perspective Camera]] — first interactive feature (orbit + zoom). Through-line: separate what *varies* (how the camera is driven) from what's *stable* (projection/view math). Composition over inheritance (controllers, not `Camera` subclasses); a control-neutral `Camera` (`position`/`target`/`up`) with the spherical params living in `OrbitControls`; single-source-of-truth/single-writer for position; DOM event listeners (arrow-field handlers, pointer capture, `dispose`); clamps as correctness (pole/zero-radius `lookAt` degeneracy); and extracting `sphericalToCartesian` as a pure function for testability. Still one MVP uniform (bind-group split deferred to the scene `Node`).
- [[Issue 15 - Scene Graph]] — the `Node`: parent/children + local transform with recursive world matrices. Through-line: a transform matrix is a *cache derived from TRS*, and a scene graph is that cache replicated down a tree (cache invalidation in a dependency tree). Decomposed TRS over raw `Mat4` (interpolation); two dirty flags not one (local ← own TRS, world ← own-or-ancestor) and the efficiency that buys; invalidation flows *down* (mark-dirty, with short-circuit), recompute flows *up* (lazy, clear-flag-is-the-cache, root `world = local`); the encapsulation contract (clone-out/copy-in, `readonly` is compile-time only on `Float32Array`); the `copy(a, dst)` direction gotcha; own-one-buffer via the `dst` arg; two-halves-of-one-link parenting. Cycle guard deferred to #106; renderer wiring + the group-2 split still pending.
- [[Issue 16 - Texture Loading]] — async loader from an image URL → mipmapped `GPUTexture` + `GPUSampler`, replacing the procedural checkerboard. Through-line: loading is a chain of format conversions (bytes → decoded pixels → texture → *filled* mip chain) where the GPU does nothing implicitly. The async-factory pattern (no async constructors); `fetch`→`createImageBitmap` decode; the sRGB-format color-space gotcha; `copyExternalImageToTexture` vs `writeTexture`; `RENDER_ATTACHMENT` needed because mip gen *renders*; mips are allocated-not-filled (manual fullscreen-triangle blit per level, encoder ordering = the dependency, `mipmapFilter: 'linear'` to engage them). Generated `public/textures/uv-grid.png` as a test asset; GPU loader tested via a mocked device + stubbed `fetch`.
- [[Issue 19 - Resize Handling]] — survive a window resize. Through-line: resize is a *consistency* problem — canvas drawing buffer, depth texture, and camera aspect are pinned at construction and must move together. Why there's no crash today (buffer also frozen → color/depth stay consistent → just CSS-stretched/blurred), and that the fatal attachment-size-mismatch is the trap the fix introduces if you resize the buffer without recreating depth. The three coupled updates (resize buffer, recreate+`destroy()` depth, update aspect); ownership (the render loop owns the depth texture as a `let` so `render()` sees the new one; don't reassign params); debounce via frame-coalescing (`ResizeObserver` sets a flag, `frame()` applies once — GPU churn on the render timeline) over a timer; the initial observer fire and the `max(1, …)` clamp. Added `Camera.setAspectRatio`. Caps the core of Phase 1.
- [[Issue 18 - Hundred Cubes]] — perf sanity check: 100 cubes, unique transforms. Through-line: a uniform buffer is a single slot, so N objects need N memory regions — the per-frame/per-object split (#13) made real. The aliasing trap (rewriting one buffer between draws → 100 identical cubes, because draws read the last value at submit); per-frame vs per-object data; chose dynamic offsets (one buffer, per-draw `setBindGroup` offset) over many-bind-groups, deferring instancing to #113; 256-byte offset alignment + slot padding; dynamic bindings need an *explicit* bind-group layout, so `Material` was *parameterized* (optional layout, falls back to `'auto'`) rather than hardcoded — the failing tests being the signal not to couple a general class to one use case. Plus two off-by-ones with different detection stories (array access caught by TS under `noUncheckedIndexedAccess`; buffer-offset overrun only at runtime). Result: 100 draws · ~10 ms · 100 FPS (vsync-capped) → passes; draw-call cost is linear → instancing (#113).
- [[Issue 17 - Blinn-Phong]] — the cube gets lit (single directional light: ambient + diffuse + specular). Through-line: lighting is a *data-flow demand* that reshapes the pipeline, not a shader add-on. Three structural changes it forced: per-vertex **normals** (sharp edges → duplicated verts; a data-driven face generator replacing the hand-edited array); **un-fusing the MVP** into `model` + `viewProjection` to recover world-space position/normal (and the **normal matrix** = inverse-transpose, because non-uniform scale rotates normals the wrong way); and a real **uniform block** with WGSL std140 alignment (vec3 aligns 16, mat3x3 is 48 so pass `normalMatrix` as mat4, scalars packed into vec3 tails → 240 bytes). The math: half-vector `H` (Blinn vs Phong), Lambert diffuse with `max(·,0)`, `pow(N·H, shininess)` specular, and the combine (ambient/diffuse × surface color, specular × light color only). Verification insight: the light is world-fixed — orbiting moves the camera, so the bottom face is *correctly* dark. Added `Camera.worldPosition`. Placeholder until PBR (#35, Phase 4).

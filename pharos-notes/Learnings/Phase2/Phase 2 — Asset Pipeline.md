# **Milestone goal**
Load real-world assets — glTF scenes with KTX2 textures — through a managed loader. The engine stops being a triangle demo and starts showing content artists make.

# Learning Notes

- [[Issue 20 - glTF Loader]] — a minimal `.glb` loader behind a `GltfScene` importer boundary. Through-line: a loader is a *translation across a boundary* (authoring-friendly de-interleaved/indirection → GPU-friendly interleaved `Mesh` + transform tree), and the engine never learns what glTF is. The indirection ladder (mesh→primitive→accessor→bufferView→buffer); two output views (`roots` hierarchy vs flat `renderables` draw list); `.glb` binary parsing with `DataView` little-endian + fail-loud; a typed manifest (literal unions for exhaustiveness, optional-mirrors-the-format); accessor decode (the alignment trap solved free by `slice`; the typed-array constructor union; the `ArrayBufferLike` vs `ArrayBuffer` saga — fix types at the producer); interleaving an unordered attribute map into an ordered buffer; matrix-or-TRS node decomposition (loose type, runtime resolve); two-pass tree assembly; and a demo (normals material) that surfaced a latent `Material.bind` bug. Meta-lesson throughout: **`tsc` clean ≠ correct** — loop bounds, `forEach` arg order, dropped branches, `0`/`''` falsiness all compile green.

- [[Issue 21 - PBR Material Params]] — carry each model's PBR material (metallic-roughness) as data, ahead of the shader. Through-line: separate the *finish* from the *shape*, and lay the data pipe before the tap. Normalize glTF's nested `pbrMetallicRoughness` into a flat engine-native `PbrMaterial { baseColor, metallic, roughness }` at the importer boundary; resolve spec defaults (white / metallic 1 / rough 1, including the no-material default) via one `?.`→`??` chain; name a type for what it *is* (`PbrMaterial`, not a vague `-Params` suffix); and two type traps — a field whose name must match the JSON key exactly (the cast trusts your spelling), and the `number[]`→4-tuple bridge. Textures (#22) and the PBR shading math (Phase 4 #35) deferred.

- [[Issue 22 - Texture and Sampler Import]] — load glTF textures + samplers and attach them to materials (the Duck gets its real skin). Through-line: a resource loader is two separable jobs — async *acquisition* (decode bytes → GPU texture) vs sync *assembly* (reference by index); isolating the async into one `Promise.all` pass dedups and is the on-ramp to #24's `AssetManager`. The three-way texture→source+sampler indirection; images embedded in the BIN (decode via bufferView → `Blob` → `createImageBitmap`, the byte-source twin of #16's URL path); GL sampler enums → `GPUSamplerDescriptor` (typed `number` for graceful fallback, the minFilter→min+mipmap split, a double-`??` for absent-field + unknown-enum defaults); the `flipY` gotcha (glTF top-left, no flip); and per-model shader selection in the demo (Box has no UVs → normals; Duck → textured). Recurring type traps: inference-too-narrow, literal widening, `exactOptional` conditional-spread, and `...(cond && x)` vs `...(cond && { x })`.

- [[Issue 23 - KTX2 and Basis Loader]] — load GPU-compressed textures (KTX2/Basis) that stay compressed in VRAM. Through-line: author one supercompressed file, transcode it at load to whatever the GPU supports. Block-compressed formats + their hardware fragmentation (why Basis exists); device-feature gating at `requestDevice`; format selection (BC→ASTC→ETC2→uncompressed fallback, with `basisFormat` as a seam from the transcoder's enum); compressed upload with block-based `bytesPerRow` and no mip-gen; integrating an Emscripten WASM transcoder (lazy singleton, `locateFile`, and hardcoding the stable `transcoder_texture_format` integers when the module's enum isn't exposed); and a headless-unverifiable part pair-debugged by running it in the browser. Provenance gotchas (Khronos sources; Git-LFS pointer files). glTF-native KTX2 (`KHR_texture_basisu`, #127) deferred.

- [[Issue 24 - AssetManager]] — a reference-counting cache that owns asset *lifetime*, not asset *decoding*, generalizing the per-file "load once, reference by index" pass into one reusable policy. Through-line: the manager counts references and disposes deterministically while a single injected `load` does the work. Generic over `T extends Disposable` (policy separated from decode mechanism); **cache the promise, not the asset** so concurrent in-flight acquires single-flight onto one load; symmetric `acquire`/`release` (borrow/return, like `malloc`/`free`) with deterministic dispose-at-zero (GPU resources can't wait for GC); dispose scheduled via `asset.then(dispose)` because the last release may land mid-load; and the failed-load trap — a rejected load would poison the URL forever, so evict it with an **identity-guarded** `.catch` that survives the release→reacquire (E1/E2) race without nuking a fresh entry. Plus async-lifecycle testing with mocked disposables and a microtask `flush()`.

- [[Issue 112 - AssetUrl Helper]] — one function owns the GitHub Pages deploy-base prefix so call sites can't forget it. Through-line: a bug that only shows in production is a centralization smell — make the correct path the only path. Absolute `/asset` URLs 404 under the `/pharos/` subpath while working in dev (`/`); the durable fix isn't prefixing `import.meta.env.BASE_URL` everywhere (#110/#111 did one site) but having exactly one place that knows the prefix exists — verified by grep (the only `BASE_URL` left in `src/` is inside the helper). Injected, defaulted `base` param for a mock-free unit test (the `AssetManager` DI move again); leading-slash strip so `base` (always ends in `/`) joins cleanly; another `tsc`-clean-≠-correct catch (a `${base}strippedPath` missing its interpolation); and the bundled-vs-runtime split (`?url` module imports for source assets, the helper for `public/` paths that resolve at runtime). Six call sites migrated.

- [[Issue 26 - Damaged Helmet]] — load the industry-standard PBR test asset and watch the Phase 2 pipeline absorb it with no new engine code. Through-line: the real test of a loader is an asset you didn't build it around — DamagedHelmet went URL→screen through the existing glTF loader, `assetUrl`, and texture import, the whole "implementation" being one `loadModel(...)` entry. Provenance re-checked (real `.glb`, not a Git-LFS pointer); graceful degradation is what made it free (the loader skips unmodeled attributes, and binds only baseColor while the other four maps load-but-wait for Phase 4 PBR); placeholder shading is honestly just baseColor on unlit geometry; headless can't see it, so coverage is a parse/interleave regression + an in-browser confirm; and the `AssetManager` is *still* uncalled by design — a lone helmet shares nothing, so its dedup waits for Sponza (#27).
